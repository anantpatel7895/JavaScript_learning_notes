# Final Recommendation
- Use const by default
- Use let if the value needs to change
- Avoid var

👉 Simple rule:
> const > let > var (don’t use var)


# there is 5 point to remember about variable
- declaration without assignment allowed or not
- Redeclaration
- Reassignment
- Scope
- Hoisting
- Temporal Dead Zone (TDZ)


- Declaration without assignment is allowed for **var** and **let**, but not for **const**.
- Redeclaration is allowed only for **var**, not for **let** and **const**.
- Reassignment is allowed for var and let, but not for const.
- var is function-scoped, while let and const are block-scoped.
- var is hoisted and initialized in contrast let and const only hoisted but not initialized.
