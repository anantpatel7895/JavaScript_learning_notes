# What is REACT STATE?

React state is a built-in object that allows components to create and manage their own data. It is used to store information that can change over time and affect how the component renders. 

- When the state of a component changes, React re-renders the component to reflect the new state.
- When state changes, the Component function runs again. It returns a brand new Element. The old element is thrown away, and the new one is used to figure out what to change on the actual screen.
