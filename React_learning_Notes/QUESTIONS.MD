### 1. Question: What is JSX in React?

>JSX is a syntax extension for JavaScript recommended by React for describing
what the UI should look like.

### 2. Question: Can JSX be directly rendered by browsers?
> No, browsers can’t understand JSX. It needs to be transpiled to regular JavaScript
using tools like Babel.

### 3. Question: Is JSX mandatory in React?
> No, JSX is not mandatory, but it’s a widely used and convenient way to write
React components.

### 4. Question: How do you render a variable in JSX?
> Use curly braces {} to embed variables in JSX, like {myVariable}
